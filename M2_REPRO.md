## 5. Key threats

1. **What "reproduced" means here.** This is a computational reproduction: the authors'
   code, run on the authors' processed data with the authors' seed, gives the authors'
   numbers. It shows the clustering step is deterministic and correctly packaged. It cannot
   detect an error earlier in the pipeline (repository mining, RefactoringMiner, the daily
   refactoring density calculation), because none of that is in the package.
2. **Project count still unexplained.** The 1,604 releases come from 157 projects, not the
   207 the paper reports (M1_PLAN.md, section 9, item 4).
3. **Seed dependence.** The result was obtained with one seed. Whether the four patterns,
   and their names, survive other seeds is RQ2.
4. **Resolved: label order.** The exact match confirms that the authors' shipped `labels`
   list is in the same order as the releases (M1_PLAN.md, section 9, item 5).
